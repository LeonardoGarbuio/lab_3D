3D Virtual Chemistry Laboratory 🧪
Uma plataforma de experimentação química virtual baseada em tecnologias web 3D, desenvolvida como projeto de pesquisa acadêmica no IFPR (Instituto Federal do Paraná).
O objetivo deste projeto é democratizar o acesso a laboratórios de química, permitindo que estudantes realizem experimentos complexos em um ambiente seguro, interativo e visualmente rico, eliminando barreiras físicas e de custo.
🚀 Funcionalidades
￼ Visualização 3D Imersiva: Renderização de moléculas e equipamentos em tempo real utilizando tecnologias WebGL.
￼ Simulação de Reações: Motor de lógica química para validação e acompanhamento de experimentos em tempo real.
￼ Interface Educacional: Design intuitivo focado na acessibilidade e na experiência de aprendizagem do aluno.
￼ Multiplataforma: Acessível diretamente pelo navegador, sem necessidade de instalação de software pesado.
🛠️ Tecnologias Utilizadas
￼ Front-end: React.js
￼ Renderização 3D: Three.js / WebGL
￼ Lógica de Simulação: JavaScript / TypeScript
💻 Como Rodar o Projeto
🔬 Pesquisa Acadêmica
Este projeto está vinculado a pesquisas acadêmicas no IFPR - Instituto Federal do Paraná, com o propósito de investigar a eficácia de ambientes virtuais na redução da lacuna entre a teoria e a prática no ensino de ciências naturais. Acreditamos que a tecnologia é a chave para transformar a educação experimental no Brasil, tornando-a inclusiva e inovadora.
